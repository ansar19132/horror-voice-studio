# 🎙️ Horror Voice Studio Pro

Free, cinematic AI voiceover studio for faceless horror YouTube channels.

- Paste your script → auto emotion detection per sentence
- Manual director controls: emotion, voice, pause, emphasis
- Multi-voice cast: narrator + characters, auto dialogue casting
- Outputs: MP3 + sentence timing map (JSON) + SRT captions
- Voice lock: your channel's signature voice stays consistent

Built with Streamlit + edge-tts. Free, no API key needed.
